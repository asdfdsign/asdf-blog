- 모바일 우선. 터치 타겟 44×44px 이상. 가로 스크롤 금지.

## 사용자의 요구 (그대로 옮김)

> 포모도로 타이머. **원형 그래픽의 직관적 디자인**으로.

"직관적" 을 이렇게 해석하고 spec 에서 구체화하라:
- 화면 한가운데 **큰 원 하나**. 남은 시간이 원의 호(arc)로 줄어드는 게 첫눈에 보인다. 숫자(`mm:ss`)는 원 안에.
- 지금이 **집중인지 휴식인지**가 색·문구로 즉시 구분된다 (집중 = 포인트 컬러, 휴식 = 차분한 색. 다크·라이트 양쪽 변수로).
- 버튼은 최소로: 시작/일시정지 하나(상태에 따라 라벨·아이콘 바뀜), 건너뛰기, 리셋. 설정은 접어 둔다.
- 설명 없이 처음 보는 사람이 10초 안에 쓸 수 있어야 한다.

## spec.md 에 반드시 담을 것

1. **한 줄 소개** — 카드용 제목과 설명(한국어, 40자 안팎).
2. **타이머 모델** — 기본값 집중 25분 · 짧은 휴식 5분 · 긴 휴식 15분 · 4회마다 긴 휴식. 세션 전환을 자동으로 할지 수동(버튼)으로 할지 근거와 함께 정한다. 오늘 완료한 포모도로 수를 원 아래에 점(●○○○)으로 보일지.
3. **정확도** — `setInterval` 로 초를 세면 탭이 뒤로 가거나 절전에서 어긋난다. **종료 시각(`endAt` 타임스탬프)을 기준**으로 남은 시간을 계산하고 `requestAnimationFrame`/`setInterval` 은 화면 갱신에만 쓴다. 일시정지는 남은 ms 를 저장. 탭이 숨겨진 사이 끝났으면 돌아왔을 때 즉시 완료 처리. 이 방식을 spec 에 명시.
4. **원형 그래픽 구현 방식** — SVG `<circle>` 두 개(트랙 + 진행) + `stroke-dasharray/offset`, 또는 `conic-gradient`. 선택과 근거(부드러움, 접근성, 다크 모드, 렌더 비용). 진행 방향(시계 방향으로 줄어듦), 선 굵기, 끝 모양(`stroke-linecap: round`), 세션 바뀔 때 색 전환, 마지막 10초 강조 여부. 원의 크기는 `min(폭, 높이)` 기준으로 iframe 480px 과 폰 세로 화면 양쪽에 맞게.
5. **알림** — 세션 끝났을 때 어떻게 알리나. 소리(짧은 톤, Web Audio 로 파일 없이 합성), 탭 제목에 남은 시간 표시(`(12:34) 집중 — 포모도로`), 브라우저 Notification API 는 **권한 요청이 불쾌하므로 1차 제외**할지 결정. 소리 켜기/끄기 토글은 둔다. 자동 재생 정책(사용자 제스처 후에만 AudioContext) 처리 방식.
6. **설정** — 시간 길이(집중·짧은·긴)와 긴 휴식 간격을 바꿀 수 있게. 접이식 패널(`<details>`) 또는 별도 화면. 범위(1~90분), 저장 키 `pomodoro:settings`. 타이머 진행 중에 바꾸면 어떻게 되나.
7. **상태 저장** — `pomodoro:state`(현재 세션 종류, `endAt` 또는 남은 ms, 일시정지 여부, 완료 수, 날짜). 새로고침해도 이어진다. 날짜가 바뀌면 완료 수 리셋. 키 접두사로 블로그·스도쿠와 충돌 없음.
8. **UI 흐름과 레이아웃** — 모바일 한 열: 세션 라벨 → 원 → 버튼 줄 → 완료 점 → 설정(접힘). 임베드 모드에서는 header·설정 숨김. 키보드: Space 시작/정지, `S` 건너뛰기, `R` 리셋 (포커스가 입력 필드에 있을 땐 무시).
9. **접근성** — 원은 `role="timer"` 또는 `aria-live` 로 남은 시간을 **매초가 아니라 분 단위·마지막 10초·세션 전환 때만** 읽게. 색 외의 단서(세션 문구, 아이콘). 버튼 라벨. `prefers-reduced-motion` 이면 호 전환·펄스 애니메이션 끔.
10. **파일 구조** — `index.html`, `style.css`, `theme.js`, `timer.js`(DOM 의존 없는 순수 타이머 로직: 상태 전이·남은 시간 계산·다음 세션 결정 — `window.Pomodoro` 노출), `app.js`(UI·SVG·오디오·저장), `test.html`(timer.js 테스트: 세션 전이, 4회마다 긴 휴식, 일시정지/재개 시간 계산을 **가짜 시계(now 를 인자로)** 로 검증).
11. **`timer.js` 공개 함수 목록** — 이름·입력·출력. `now` 를 주입받아 테스트 가능하게.
12. **검증 체크리스트** — Review 용. 스도쿠 review.md 수준으로. 최소: 정확도(1분 타이머를 돌리며 `Date.now()` 와 비교해 오차 < 200ms; 탭 숨김 시뮬레이션 뒤 돌아왔을 때 시간 일치), 원 호가 남은 비율과 일치(`stroke-dashoffset` 실측), 세션 전환·색 전환, 소리(사용자 제스처 후 재생, 토글 끄면 무음), 설정 변경 반영·저장, 새로고침 이어하기, 375px 가로 스크롤 없음, iframe 300×480 안에 원+시간+버튼 보임, 라이트/다크 대비, 키보드 단축키, 콘솔 에러 없음.
13. **안 하는 것** — 1차 제외 목록(Notification API, 통계 그래프, 할 일 목록 연동, 여러 타이머, 오프라인 등).
