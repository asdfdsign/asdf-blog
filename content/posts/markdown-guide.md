## 문단과 강조

연속된 줄은 하나의 문단으로 합쳐집니다.
이 줄은 윗줄과 같은 문단입니다.

빈 줄을 넣으면 새 문단이 됩니다. **굵게**, *기울임*, ~~취소선~~, 그리고 `인라인 코드`를 쓸 수 있습니다. 인라인 코드 안의 `<b>태그</b>`는 그대로 보여야 합니다.

***굵고 기울임***은 아직 지원하지 않습니다. 2차 목록에 있습니다.

## 목록

순서 없는 목록:

- 첫 번째 항목
- **굵은** 항목
- `코드`가 있는 항목

순서 있는 목록:

1. 먼저 이것
2. 그 다음 이것
3. 마지막으로 이것

중첩 목록은 아직 안 됩니다.

## 인용

> 인용 안에서도 **강조**와 `코드`가 됩니다.
> 여러 줄을 이어 쓰면 한 문단이 됩니다.

## 코드 블록

```js
// 파서의 진입점
export function render(src) {
  const { body } = parseFrontmatter(src);
  return renderBlocks(body);
}
```

<!-- HTML 도 이스케이프되어 그대로 보입니다 -->

</div>
